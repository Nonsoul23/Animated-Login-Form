OrangeFusion Login UI ✨

OrangeFusion Login UI is a modern, responsive login and registration form created using HTML, CSS, and JavaScript.
This project features an elegant orange gradient theme, smooth animations, and a toggle-based interface that allows users to easily switch between Sign In and Sign Up modes.

🚀 Features

✅ Fully responsive design
✅ Modern orange gradient theme
✅ Interactive toggle animation between Sign In / Sign Up
✅ Social media login icon buttons (Google, Facebook, GitHub, LinkedIn)
✅ Smooth hover effects and transitions
✅ Lightweight and easy to customize

🧩 Tech Stack

HTML5 – structure of the form

CSS3 – styling and animations

JavaScript (Vanilla) – interactivity and transitions

🧠 How It Works

When the user clicks “Sign Up”, the panel slides and the form switches to the registration interface.

When the user clicks “Sign In”, the panel moves back to the login form.

All animations and transitions are handled with smooth CSS effects.
